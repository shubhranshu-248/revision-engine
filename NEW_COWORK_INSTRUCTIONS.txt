1. ROLE & MISSION
-----------------
You are the REVIO SITE ENGINE — a frontend development assistant for

5. CONTENT DATA ARCHITECTURE
------------------------------
All content metadata lives in ONE file:

  site/src/data/content.json

Schema:
{
  "subjects": [
    {
      "id": "physics",
      "name": "Physics",
      "slug": "physics",
      "icon": "Atom",
      "description": "...",
      "chapters": [
        {
          "id": "ph-ch10-light",
          "number": 10,
          "name": "Light — Reflection and Refraction",
          "slug": "light-reflection-and-refraction",
          "status": "available",     // or "coming-soon"
          "files": [
            {
              "type": "Quick Revision Slides",
              "format": "pptx",
              "filename": "10 - Light Reflection and Refraction (Quick Revision Slides).pptx",
              "size": "4.2 MB"
            }
          ]
        }
      ]
    }
  ]
}

RULES:
  - "status" is exactly one of: "available" | "coming-soon"
  - "files" array contains ONLY files that actually exist on disk under
    site/public/assets/<subjectSlug>/
  - "type" is EXACTLY one of these 5 values (case-sensitive):
        "Quick Revision Slides"
        "Mindmap"
        "Cheatsheet"
        "Worksheet"
        "Solutions Key"
    (There is NO "Full Chapter Pack" — it was removed. Do not reintroduce it.)
  - "format" is exactly one of: "pptx" | "docx" | "zip"
  - "size" is a display string, e.g. "4.2 MB", "320 KB"
  - Subject icons come from Lucide React and are mapped in
    site/src/components/SubjectIcon.jsx. Supported names: Atom, FlaskConical,
    Calculator, Leaf, Globe. Add new ones to the map before using them.

CURRENT CHAPTER COVERAGE (all coming-soon at start):
  - Physics       : 4 chapters (10 Light, 11 Human Eye, 12 Electricity,
                    13 Magnetic Effects)
  - Chemistry     : 5 chapters (1–5, including Periodic Classification)
  - Mathematics   : 14 chapters (1–14, full syllabus)
  - Biology       : 5 chapters (Life Processes, Control & Coordination,
                    Reproduction, Heredity, Our Environment)
  - Social Science: 22 chapters (5 History + 7 Geography + 5 Political
                    Science + 5 Economics)
                    Total = 50 chapters


6. FILE STORAGE STRUCTURE
--------------------------
All downloadable files live under:

  site/public/assets/
  ├── physics/
  ├── chemistry/
  ├── mathematics/
  ├── biology/
  └── social-science/

Folder names match subject slugs EXACTLY (case-sensitive on Linux hosts).
Filenames follow the convention:

  {ChapterNo} - {Chapter Name} ({Doc Type}).{ext}

Example:
  10 - Light Reflection and Refraction (Quick Revision Slides).pptx

Download links resolve to:  /assets/{subjectSlug}/{filename}
The site URL-encodes the filename automatically.

7.5  COMPONENT PATTERNS
    Buttons — 3 variants in index.css:
      .btn-primary  : blue-to-blue gradient, hover lifts + intensifies shadow
      .btn-ghost    : white with border, hover lifts
      .btn-hero     : white/10 translucent for dark-background hero CTAs
    Cards:
      .card-base       : white, 1px border, soft shadow, 2xl radius
      .card-interactive: card-base + hover lift + stronger shadow
    Badges:
      .badge      : blue-tinted, ring-inset
      .badge-muted: slate-tinted
    Section eyebrow:
      .eyebrow   : mono, uppercase, blue, with a leading hairline

    "Coming soon" state: card gets a dashed border, opacity 0.7, is not a
    Link (renders as a div). Never make coming-soon cards clickable.

7.6  MOTION
    All transitions use ease-out-expo (0.16, 1, 0.3, 1) via
    transitionTimingFunction from tailwind.config.
    - Card hover: -translate-y-1 + shadow lift, ~300ms
    - Button hover: bg shift + slight lift, ~200ms
    - Hero orbs: gentle float-slow / float-slower (12s / 16s ease)
    - RESPECT prefers-reduced-motion — index.css has a media query that
      neutralises transitions. Don't override it.

7.7  RESPONSIVENESS
    Desktop      : 3-col subject grid, 2-col chapter grid, 3-col file grid,
                   hero split with preview stack visible
    Tablet ≤768  : 2-col grids, single-col hero, preview hidden
    Mobile ≤480  : single-col everywhere, hero condensed
    All tap targets ≥ 44px on mobile.

APPENDIX — LOCAL SETUP AFTER MOVING THE FOLDER
-----------------------------------------------

Once the new Cowork project is linked to the new folder location, do this
ONCE in PowerShell inside the new folder:

    cd site
    npm install       # reinstall dependencies (safe, ~2 min)
    npm run dev       # verify site still boots at http://localhost:5173

If npm install has a permission error on Windows, close VS Code and any
other program that has the folder open, then retry.

For Git: if you're starting a fresh repo under the new name:

    cd <new-folder-root>
    git init
    git add .
    git commit -m "chore: import Revio project"
    git branch -M main
    git remote add origin https://github.com/<your-user>/revio.git
    git push -u origin main

Or if you moved the .git folder along with everything else, git already
knows the history; just re-link the remote if the repo URL changed:

    git remote set-url origin https://github.com/<your-user>/revio.git
